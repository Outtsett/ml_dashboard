Key Discovery: MoE Models

Qwen3 MoE models have 30B total parameters but only 3B active per inference. This means ~6GB VRAM for "30B-class" quality. Your GPU can run these at full speed with room to spare.

Performance Tip

Set OLLAMA_KV_CACHE_TYPE=q8_0 to halve KV cache memory with minimal quality loss. This is critical for long-context agent conversations. Without it, a 256K context window on a 30B model would consume all 16GB VRAM just for the cache.
