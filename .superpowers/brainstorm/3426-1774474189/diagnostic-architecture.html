Training Diagnostic Architecture

4-tier system — each tier answers a progressively deeper question about model quality

1

Sampler Health

"Is the algorithm working correctly?"

Effective Sample Size (ESS)

Are Gibbs samples independent? ESS < 50 = poor mixing, wasted iterations. Tells you if 500 iterations produced 500 useful samples or 50.

Autocorrelation (lag-k)

How correlated are consecutive samples? High autocorrelation = sampler stuck in a mode. Directly determines thinning interval.

Burn-in Adequacy

Has the chain left initialization influence? Detects Geweke diagnostic: compare first 10% vs last 50% of chain. If statistically different, burn-in too short.

Iteration Timing

Per-step wall clock (FFBS time, emission sampling time, transition sampling time). Identifies bottlenecks.

Existing metrics kept: log_likelihood, assignment_stability (already working)
2

Regime Discovery

"What is the model finding?" — ENTIRELY NEW

Per-Regime Profile Cards

For each active regime: mean return, volatility, Sharpe ratio, bar count, dwell distribution, top transition targets. Updated every N iterations. THIS is what tells you if the regimes make sense.

Regime Separation Heatmap

Pairwise Bhattacharyya distance between regime emission distributions. Shows which regimes are distinct vs. overlapping. If two regimes overlap >70%, the model is over-segmenting.

Feature Attribution per Regime

Which features define each regime? Computed from emission parameter divergence (mu_k differences across regimes weighted by 1/var_k). Identifies dead features contributing nothing.

Regime Birth/Death Timeline

When did regimes appear, stabilize, or collapse during sampling? Tracks active count over iterations with lifecycle events. Shows model exploration path.

Beta Weight Evolution

Stacked area chart of stick-breaking weights over iterations. Shows how the model redistributes probability mass across regimes as it trains.

3

Regime Quality

"Is what it found useful for trading?" — MOVED FROM POST-HOC TO LIVE

Tradeability Score (composite)

Combines dwell time adequacy + return separation + regime count balance into a single 0-100 score. Updated every 25 iterations. If this doesn't improve, you know the model isn't finding tradeable structure.

Signal-to-Noise Ratio

Ratio of "real" regime transitions (sustained 5+ bars) to noise transitions (flip-back within 2 bars). High SNR = clean signals. Low = your transition signals are mostly noise.

Assignment Confidence Distribution

Histogram of per-bar assignment confidence (posterior probability of assigned regime). Bimodal = some bars are ambiguous. Uniform high confidence = model is sure of every bar.

Live Silhouette Score

Cluster separation metric computed every 50 iterations on the current assignments. Currently only runs post-hoc — moving it to live lets you see quality evolve.

Per-Regime Return Distributions

Violin/box plots showing log-return distribution per regime. If distributions overlap heavily, regimes aren't distinguishing different market conditions.

4

Parameter Guidance

"What should I change?" — THE MISSING PIECE

Automated Recommendations

Rule engine that watches metrics and generates actionable text: "K=12 regimes detected but silhouette=0.15 — regimes overlap. Reduce alpha from 1.0 to 0.3 to consolidate." Not predictions — deterministic rules based on metric thresholds.

Convergence Forecast

Exponential fit to stability curve → projects when 95% stability will be reached. "At current rate, converges at iteration 420. You set 500 — sufficient." or "Won't converge before iteration limit — increase gibbs_iter."

Quality Gates (live)

Pass/fail indicators that update during training. Red/yellow/green for: regime count in range, stability above threshold, dwell time adequate, separation sufficient. Gives instant visual read on model health.

Anomaly Detection

Detects training pathologies: LL drops >10% between iterations (mode collapse), K oscillates without settling (mixing failure), stability plateau then crash (prior conflict). Alerts with diagnosis.

Cross-Run Comparison

Side-by-side table: "Run #7 (alpha=0.5, kappa=50) → K=4, silhouette=0.42, dwell=8.3 vs Run #8 (alpha=1.0, kappa=50) → K=9, silhouette=0.18, dwell=2.1". Tracks which configs work.

What This Changes

Before (current)

  • 7 convergence line charts during training
  • Post-hoc evaluation gives a letter grade
  • No regime-level insight during training
  • No parameter recommendations
  • No cross-run comparison
  • "Grade D" with no explanation of why

After (proposed)

  • 4-tier diagnostic system with 20+ metrics
  • Live regime profiles updating during training
  • Feature attribution showing what drives each regime
  • Automated parameter recommendations
  • Quality gates with real-time pass/fail
  • "Alpha too high → 12 overlapping regimes. Reduce to 0.3."
