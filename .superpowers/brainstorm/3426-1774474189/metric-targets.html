Metric Targets — What Good Looks Like

Every metric has a target range. Green = on track. Yellow = needs attention. Red = problem. No guessing.

Model Performance Targets

Metric Green Yellow Red What To Do If Red
Silhouette Score > 0.40 0.20 – 0.40 < 0.20 Regimes overlap. Reduce alpha (fewer regimes) or remove noisy features.
Davies-Bouldin < 1.0 1.0 – 1.5 > 1.5 Clusters bleed together. Check emission heatmap for similar regimes → merge.
Calinski-Harabasz > 500 100 – 500 < 100 Within-cluster variance too high. Regimes aren't tight. Try more iterations or different features.
Adjusted Rand Index > 0.85 0.70 – 0.85 < 0.70 Assignments still changing between iterations. Model hasn't converged. Extend burn-in.

SHAP & Feature Attribution Targets

Metric Green Yellow Red What To Do If Red
Top Feature SHAP Dominance < 40% 40% – 60% > 60% Model over-relies on one feature. If that feature fails, everything fails. Add diverse features.
Dead Features (|SHAP| < 0.01) 0 – 2 3 – 5 > 5 Remove dead features — they add noise without signal. Fewer features = cleaner regimes.
SHAP Rank Stability (post burn-in) Top 3 unchanged Top 3 shuffle 1x Ranks unstable Model hasn't decided what matters. Features may be too correlated. Check correlation matrix.
Inter-Regime SHAP Variance > 0.15 0.05 – 0.15 < 0.05 All regimes use features the same way = not really different states. Need features that discriminate.

Model Internals Targets

Metric Green Yellow Red What To Do If Red
Active Regimes (K) 3 – 6 7 – 10 > 10 or < 2 Too many: reduce alpha. Too few: increase alpha or add features. Market typically has 3-6 distinct states.
Min Regime Size > 5% of bars 2% – 5% < 2% Tiny regimes = noise artifacts. Reduce alpha to consolidate. Or increase kappa for stickiness.
Max Regime Dominance < 50% 50% – 70% > 70% One regime eating everything. Model sees one dominant state. Increase alpha or add discriminating features.
Avg Dwell Time 5 – 20 bars 2 – 5 or 20 – 50 < 2 or > 50 Too short: increase kappa. Too long: decrease kappa — model only sees one persistent state.
Emission Param Separation > 1.5σ between regimes 0.75σ – 1.5σ < 0.75σ Regime emission distributions overlap. Check heatmap — similar rows = redundant regimes.
Return Separation (p-value) p < 0.01 p 0.01 – 0.05 p > 0.05 Regimes don't have statistically different returns. Model found structure, but not FINANCIAL structure.

Convergence Targets

Metric Green Yellow Red What To Do If Red
Assignment Stability > 95% 90% – 95% < 90% Extend iterations. If still unstable, ambiguous bars are genuinely between regimes.
Log-Likelihood Trend Plateaued (Δ < 0.1%) Still rising Declining or oscillating Declining = numerical issue. Oscillating = prior conflict. Check alpha/kappa balance.
ESS / Total Iterations > 20% 10% – 20% < 10% Sampler isn't mixing. 90% of iterations are wasted. Adjust priors or increase data.
Self-Transition (diagonal avg) 70% – 90% 50% – 70% or 90% – 95% < 50% or > 95% Low: increase kappa (more stickiness). High: decrease kappa — model sees one persistent state.

How Targets Work in the UI

Every metric card shows current value + color-coded status indicator (green/yellow/red dot).
A Quality Gate panel at the top of the training page shows pass/fail status for all critical metrics at a glance.
When a metric goes red, the Recommendation Engine surfaces specific parameter adjustments (not vague — exact: "reduce alpha from 1.0 to 0.3").
Targets are configurable per model type and adjustable as you learn what works for your data.
