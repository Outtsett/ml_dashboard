The HDP-HMM model at any iteration consists of these components. All computable per-iteration.

mu_k values (normalized). Each cell = how that regime differs from mean on that feature. High |value| = strong signal.

What this tells you
  • Regime 0 = bullish trend (positive returns, high RSI, low vol)
  • Regime 1 = volatile selloff (negative returns, high vol, high ATR)
  • Regime 2 = range-bound (all features near zero = no strong signal)
  • If two rows look identical → regimes overlap → reduce alpha
  • If a column is near-zero for ALL regimes → dead feature → remove it

Transition Matrix (pi_jk)

K×K matrix of transition probabilities. The diagonal = self-transition (stickiness). Off-diagonal = which regime follows which. This IS the regime dynamics.

Updated every iteration. Heavy diagonal = sticky regimes. Off-diagonal patterns reveal market structure.

What this tells you
  • R1→R2 (0.15) = selloffs tend to transition to range, not bull (realistic)
  • R0→R1 (0.05) = direct bull→crash rare (makes sense)
  • R2→R0 (0.12) = ranges break to upside more than downside
  • If any diagonal <0.5 → regime too short to trade → increase kappa
  • If any off-diagonal is >0.3 → two regimes are really one cycle

Beta Weights & State Sequence

The stick-breaking weights (beta) and per-bar assignments — the core output of the model.

Beta Evolution (stacked area)

How the model distributes probability mass across regimes over iterations. Watch regimes grow, shrink, or collapse to zero. A regime's beta weight = its "importance" in the model.

Assignment Confidence

Per-bar posterior probability of the assigned regime. Computed from forward-backward alpha values. Shows where the model is certain vs. ambiguous.

  • High confidence (>0.9) → model is sure about this bar's regime
  • Low confidence (<0.6) → bar sits between regimes → transition zone
  • Histogram of confidences shows overall model certainty

Parameter Traces

How the model's actual parameters evolve across Gibbs iterations.

mu_k traces

Per-regime mean across iterations. See when regime means stabilize — that's convergence of the model parameters, not just assignments.

var_k traces

Per-regime variance evolution. Wide variance = regime captures diverse bars. Narrow = tight cluster. Watch for variance collapse (→0).

pi_jk diagonal traces

Self-transition probability per regime. Not the mean — the individual regime stickiness. Shows which regimes persist vs. which are fleeting.

The Gap

Current: The model computes mu_k, var_k, transition_matrix, beta, state_sequence every iteration. But only 7 summary scalars get emitted (log_likelihood, num_regimes, stability, self_transition, switch_rate, avg_dwell, entropy).

Proposed: Emit the actual model state — emission parameters, full transition matrix, per-regime profiles, beta weights, assignment confidence — at regular intervals. The frontend renders them as live-updating heatmaps, profile cards, Sankey diagrams, and parameter traces.
