SHAP Evolution Over Training

How feature importance shifts as the model trains. Early iterations = random. Later = stable feature hierarchy.

  • If SHAP rankings keep shuffling after burn-in → model hasn't decided what matters
  • If one feature dominates all regimes → model might be overrelying on one signal
  • Stable SHAP hierarchy + stable assignments = converged model
  • Computed from emission parameter divergence (fast, no tree SHAP needed)

DL-Grade Model Internals

Emission Param Heatmap

K×D matrix of mu_k values. Each cell = how regime k differs from global mean on feature d. The "weights" of the model. Live-updating. Equivalent to weight histograms in neural nets.

Transition Matrix Evolution

K×K transition probabilities animated over iterations. Watch regime dynamics crystallize. Equivalent to attention maps in transformers — shows what the model predicts follows what.

Regime Centroid Scatter (PCA/t-SNE)

Feature-space projection of regime centroids. See how regimes separate in 2D. Overlap = model can't distinguish. Clean separation = distinct market states. Equivalent to embedding visualizations.

Confidence Calibration

Is the model's confidence calibrated? Plot: predicted confidence vs actual accuracy. Overconfident models produce bad signals. Equivalent to temperature scaling analysis in DL.

Per-Regime Return Distributions

Violin/histogram of log returns per regime. Shows if regimes capture genuinely different market conditions. If distributions overlap → regimes aren't useful for trading.

Dead Feature / Dead Regime Detection

Features with near-zero SHAP across all regimes = dead weight. Regimes with <1% bar allocation = empty shells. Equivalent to dead neuron detection in DL. Auto-flags for removal.
