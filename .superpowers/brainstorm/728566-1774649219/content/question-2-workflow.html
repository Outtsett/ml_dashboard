What's the workflow spine?

How should the training experience feel?

A

Guided Wizard

Distinct phases: Configure → Train → Evaluate. Step-by-step, can't skip ahead. Like a deployment pipeline. Clear progress indicator. Good for beginners, restrictive for power users.

B

Command Center (recommended)

Everything visible in zones — config panel, live metrics, results grid. No tab-switching needed. Glanceable. Like Bloomberg or a mission control dashboard. Dense but organized. Power-user focused.

C

Scrollable Notebook

Sequential cells: model card → hyperparameters → training log → results. Each run is a "chapter" you scroll through. Narrative flow. Good for review, but requires scrolling.
