# Visualizations — Data Visualization Components

8 reusable visualization components for ML model analysis and data exploration. Built with Recharts, D3, and custom SVG rendering.

## Components

| File | Visualization | Usage |
|---|---|---|
| `AnomalyTimeline.tsx` | Timeline chart with anomaly highlighting | Anomaly detection results |
| `ComponentLoadings.tsx` | PCA/factor component loading bars | Dimensionality reduction analysis |
| `ConfusionMatrixHeatmap.tsx` | Color-coded confusion matrix | Classification model evaluation |
| `EmbeddingScatter.tsx` | 2D/3D scatter plot of embeddings | Representation learning, clustering |
| `ForceDirectedCluster.tsx` | D3 force-directed graph layout | Feature interaction networks |
| `ForecastRibbon.tsx` | Forecast with confidence ribbons | Time-series prediction |
| `ResidualPlot.tsx` | Residual analysis scatter | Regression diagnostics |
| `SimilarityMatrix.tsx` | Heatmap similarity/correlation matrix | Feature correlation, model similarity |
